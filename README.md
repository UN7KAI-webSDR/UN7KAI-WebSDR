# UN7KAI WebSDR Android starter

A minimal Android app shell for accessing WebSDR.org. It is not yet a dedicated receiver; the first version opens the WebSDR directory in its embedded browser.

## Cloud build
1. Upload this folder to a GitHub repository.
2. Open the repository's Actions tab.
3. Select "Build Android APK" and press "Run workflow" (or push to main).
4. When complete, open the workflow run and download the artifact named `UN7KAI-WebSDR-debug-apk`.
5. Extract the ZIP; install `app-debug.apk` on Android (allow installing from that source if prompted).
